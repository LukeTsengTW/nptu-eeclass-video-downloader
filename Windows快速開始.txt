eeClass 影片下載器 1.7 — Windows 免安裝版

1. 將下載的 ZIP 完整解壓縮。
2. 雙擊 eeClass-Downloader.exe。
3. 貼上影片網址，按「解析影片」；首次在程式開啟的 Firefox 正常登入。
4. 選擇畫質與儲存位置，再按「下載 MP4」。

不必安裝 Python、pip、Selenium、yt-dlp 或 FFmpeg。
不必預先安裝 Firefox；程式會先尋找既有 Firefox 與快取，沒有才下載專用副本。
多筆影片：按「＋ 新增網址」，第一欄必填，其餘空白略過，再按「批次下載」。

支援 Windows 10／11 的 x64 環境，不需要系統管理員權限。
首次準備瀏覽器需要網路。日後會重用使用者 AppData 內的瀏覽器與登入設定。
若移動或換新版 EXE，仍使用相同的快取目錄，不會因為換檔案位置就重下載瀏覽器。

本程式未使用商業程式碼簽章；Windows 可能顯示「未知的發行者」。請確認檔案來自本專案的 GitHub 建置。SHA256SUMS.txt 可核對 EXE 的 SHA-256。
本版僅下載已有觀看權限的普通 MP4，不進行重新編碼。
詳細操作請參閱「使用說明.txt」。隨附 third_party_licenses 保存第三方元件授權資訊，重新散布時請一併保留。
